01 · 一个反直觉的发现

大多数人加的群，
跟你没有半毛钱关系。

仁谱把关系拆成两类：私聊（一对一说过话）和群共现（只是在同一个群里）。

「340 条私聊，0 个共同群。」
仁谱揪出来的这类人：线上从没在群里见过面，私聊却聊了几百条。 按「同群即关系」的算法，他们是隐形的；按真实数据，他们才是你最铁的关系。

消息量不是关系深度。有人消息量第一却已决裂；有人只有 22 条消息， 却是线下见过面、聊得愉快的朋友。仁谱把这两件事分开算。

02 · 它能做什么

  • ▸关系图谱60 人一屏，圈层自动分色；青色=私聊、灰色=同群、白色=自己。可拖时间轴。
  • ▸3D 关系圈以任意人为中心展开，越靠中心关系越强。拖一下就能转。
  • ▸一人一档关系谱、消息时间线、承诺与待办、最近对话。一个人是一页。
  • ▸Obsidian 导出一人一页 + 关系谱 + 时间线，反向链接自动连上，断链数为 0。
  • ▸全文搜索在几十万条消息里按关键词找人、找事、找承诺。
  • ▸本地 API16 个端点，供 Agent 直接调用；已接入 ClawHunt 任务市场。

技术底座

本地 SQLite · 单文件 HTML（零外链，断网可开）· 双击 EXE 即可跑（Windows）· 无运行时外部依赖

演示即产品

内置虚构演示库：无需导入真实数据即可现场演示全部能力， 投屏时不会泄露任何真实联系人。

03 · 隐私与落地

数据不出本机。

所有计算在你自己的电脑上完成。没有上传、没有云端、没有第三方。

本地优先 AGPL-3.0 一键脱敏 断网可演示

分享模式

一键把姓名、群名、账号标识全部替换成占位符。 公网暴露时，返回消息正文的端点直接禁用——因为搜索的价值就是内容本身， 脱敏后等于无效。
