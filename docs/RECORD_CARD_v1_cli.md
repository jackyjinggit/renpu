## 第 1 段 · 开场（黑屏，不敲命令）

【你有没有过这种情况——想查"我跟某个人什么关系来着"，翻了半小时聊天记录还是没想起来。】

【仁谱 是给你的「人脉 OS」。微信里的联系人，变成一个你能问、能写、能接的本地库。】

【现在看它怎么跑。】

## 第 2 段 · 启动（敲 2 行）

```bash
call scripts\activate-demo-env.cmd
renpu doctor
```

【先体检。它告诉你环境行不行、下一步该做什么。】

```bash
renpu init
renpu ingest --demo
```

【零配置。不用连微信，先灌一批演示数据，立刻能查。】

## 第 3 段 · 查一个人（核心画面，慢一点）

```bash
renpu who 林夏
```

【这一屏就是答案。基本信息、最近聊了什么、都在哪些群、跟谁强相关、有什么没回的事、发生过什么关键节点。】

【不用翻聊天记录，不用凭印象。】

---

## 第 4 段 · 全局（快一点）

```bash
renpu people --days 7
```

【近 7 天有来往的人。】

```bash
renpu edges
```

【关系边。谁跟谁在多少个群里同时出现过——这是社交图谱的雏形。】

```bash
renpu search 黑客松
```

【全文检索。当年谁提过什么，一秒定位。】

---

## 第 5 段 · agent 接入（重点，也是卖点）

**开第二个 cmd 窗口**，激活同一环境：

```bash
call scripts\activate-demo-env.cmd
renpu serve --port 8877
```

【起一个本地 API。任何 agent 都能通过它问。】

**回到第一个窗口**：

```bash
curl "http://127.0.0.1:8877/api/who?name=%E6%B7%AE%E6%99%93%E9%9B%AF"
curl "http://127.0.0.1:8877/api/people?days=30"
curl "http://127.0.0.1:8877/api/search?q=2026"
```

【三个端点，全 JSON 返回。你的 AI 助手挂上这个口，就能回答"我跟他什么关系"。】

## 第 6 段 · 写回（体现"活的库"）

```bash
renpu note "刚从 demo 跑到真库了" --name 林夏 --kind ai_note
renpu todo
```

【它不只能读，能写。你和你的 agent 都可以往里写——下次任何窗口打开，背景是一致的。】

---

## 第 7 段 · 接真数据（一句话带过，不演示）

【接你真的微信，只要在配置文件里写一行路径：】

```json
{ "wc_live": "<微信数据目录>\\db_storage" }
```

```bash
renpu ingest --pull
```

【同样的命令，同样的库。微信只是第一个数据源——以后想接飞书、邮件，加个 adapter 就行。】

## 万一翻车了怎么办

| 情况 | 怎么办 |
|---|---|
| 命令报错 | 别慌，说「这就是 debug 模式」，然后 `renpu doctor` 救场——**这反而真实** |
| 中文乱码 | 检查窗口是不是 cmd（不是的话换成 cmd）、执行了 activate 没 |
| 数字不对 | 说「这是合成数据，真库是 2 万多人」——反而是加分项 |
| 忘词了 | 低头看一眼这张卡，观众不会注意 |
| 彻底卡死 | 说「我们跳到最关键的」→ 直接跳第 6 段（写回），那个画面最有说服力 |

---

## 别说的三句话

1. 「这是 AI 生成的」——观众会自动打低分
2. 「这个数据库很复杂」——不复杂，说不清楚反而扣分
3. 「你可以随便用」——改成「demo 模式你可以直接试，数据是你自己的」

## 技术备忘（你自己知道就行）

- 数据隔离：demo 环境落 `%TEMP%\renpu-demo-env`，**不碰你真库**
- `activate-demo-env.cmd` 里已设 `PYTHONIOENCODING=utf-8` + `chcp 65001`
- 所有 `.cmd` 文件纯 ASCII —— cmd.exe 遇到非 ASCII 字节会解析错乱
- 端口 8877；若被占换 8788（改脚本里两处）
