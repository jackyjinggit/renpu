06 · 结论：不是虚假繁荣，但深度不够

你的人脉不是虚假繁荣，但深度不够。
核心圈 233 人是真实的（有私聊 + 群共现），圈层清晰（AI / 黑客松 / 技术）。
但真正的"铁关系"只有 6 人（≥1000 条消息），私聊高度集中（前 3 人占 40%）。
圈层有偏向：AI / 黑客松 / 技术 是主线，学术 / 论文 / 研究 很少 —— 与"独立研究者"身份有偏差。

07 · 建议：补深度、补学术、去僵尸

🎯

补深度

📚

补学术

学术 / 论文 / 研究 只有 3 个群，与"独立研究者"身份不符。 主动加 2-3 个学术圈（论文共读、研究协作、学术会议），把"工程"和"学术"平衡过来。

🧹

去僵尸

20852 个零消息联系人（95.5%）不计入"人脉"。 仁谱的"关系谱"只算有消息 + 有边的人，僵尸联系人不算资产。
